# FastJobSerch — Full Stack Starter

## Run locally
1. Install Node.js 20+.
2. Copy `.env.example` to `.env` and set a strong `JWT_SECRET` and `ADMIN_PASSWORD`.
3. Run `npm install`.
4. Run `npm start`.
5. Open `http://localhost:3000`.

The SQLite database `fastjobserch.db` is created automatically.

## Production
Use HTTPS, a strong random JWT secret, a strong admin password, and a managed database/backup strategy. The supplied sample credentials are not intended for production.
